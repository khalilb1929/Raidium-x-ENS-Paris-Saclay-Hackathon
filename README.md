# Raidium x ENS Paris-Saclay Hackathon

This repository contains experiments and trained model artifacts developed for the Raidium x ENS Paris-Saclay Hackathon. The work focuses on skin-lesion image segmentation and includes notebooks, preprocessing analyses, model comparisons, predictions, and saved checkpoints.

## Repository Contents

- `*.ipynb`: training, comparison, and evaluation notebooks
- `MedSAM/` and `Testings/`: supporting code and experiments
- `*.pth`: saved model checkpoints
- `*.png`: generated figures and prediction visualizations
- `annotated_labels.json`: annotation metadata
- `consignes`: project instructions

## Getting Started

Open the notebooks with Jupyter or VS Code and provide the dataset paths expected by each notebook. The committed checkpoints and generated figures are included as reference artifacts; reproduce experiments in a separate working directory when possible.
